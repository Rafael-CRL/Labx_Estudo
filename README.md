# Labx_Estudo

Projeto criado com objetivo de estudar Java, no Laboratório de Programação extrema (LABEX).

## Projects_Java/Labirinto

Primeira versão do jogo do labirinto: Java 21, Swing em MVC (`Model`, `Control`, `View`), fases em JSON lidas com Gson.

```bash
cd Projects_Java/Labirinto
mvn compile exec:java -Dexec.mainClass=TesouroGame.Main
```
